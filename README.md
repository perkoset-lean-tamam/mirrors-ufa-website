# mirrors-ufa-website

Лендинг «Зеркала Уфы» на Astro.

## Счётчик посещений

Cloudflare Pages Function `/api/visits` использует существующую KV-привязку `VISITS`.
Общий счётчик `count` сохраняется. В футере выводятся общий счётчик сессий и
уникальные браузеры за сегодня. На `/stats/` дополнительно выводятся повторные
сессии за сегодня и всего. Служебные страницы не увеличивают счётчики.

День определяется по времени Уфы (`Asia/Yekaterinburg`, UTC+5).
Повторный визит определяется по cookie браузера со сроком до 400 дней;
другой браузер или очистка cookie считаются новым посетителем.
Дневные и повторные показатели начинают накапливаться после развёртывания:
восстановить их из старого общего числа невозможно.

Хранилище остаётся Cloudflare KV: при одновременных запросах возможны потери
инкрементов и задержки видимости данных, поэтому показатели приблизительные.
Для строгой точности при высокой нагрузке потребуется атомарное хранилище.
Проверка логики: `node --test tests/visits.test.js`; сборка: `npm run build`.
