1. Отчёт «Поисковые запросы»: по каким реальным фразам показывали рекламу. Лишние добавляйте в минус-слова.
2. Клики и обращения по группам (звонок, MAX, WhatsApp): отключайте группы, где много кликов и нет обращений.
3. Через 2–3 недели можно переходить на стратегию с оптимизацией по конверсиям, когда накопится хотя бы 10–20 целевых действий.
